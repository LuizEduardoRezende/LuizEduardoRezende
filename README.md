## Research

**Inference of AI Models in the Robotics Language using TensorFlow Lite Micro for TinyML**

Extending the Robcmp compiler so that AI inference becomes a native capability of the Robotics Language — declarable directly in its syntax, without C++ boilerplate or manual toolchain setup. The work covers DSL design, compiler front-end restructuring, and embedded systems validation.
